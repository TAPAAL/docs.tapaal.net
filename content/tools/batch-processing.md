**Tools > Batch processing** verifies multiple nets and queries in one run. Prepare a consistent set of model and query files, select the batch input, and review the per-case results.

For command-line use, choose **File > Export > Batch Export of model and queries**. Keep the exported files, engine version, and settings with the batch output so that results can be reproduced.

Batch processing is useful for comparing constant valuations, model variants, or a collection of exercises. Check that each case uses the intended query category, engine, extra-token capacity, and reduction settings.

See [Reproducible verification](/verification/gui-workflow/#reproduce-a-result) and [Command Line](/command-line/) for related workflows.

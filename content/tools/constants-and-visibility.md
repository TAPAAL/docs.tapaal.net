title: Constants and visibility
weight: 50
lastmod: 2026-08-29
description: Manage constants and display options for colors, intervals, token ages, and transitions.
---

The constants and color-types/variables views help you inspect values used throughout a model. Use constants for values that you expect to vary between verification runs, such as a capacity or deadline. Use descriptive names and use each constant consistently in intervals, invariants, expressions, and queries.

The **View** menu can show or hide components, shared places and transitions, queries, constants, colored tokens, token ages, intervals, enabled transitions, and future-enabled transitions. Hiding a label changes the view, not the model semantics.

For colored models, inspect color types, variables, and arc expressions before simulating or verifying. Their values determine which tokens an arc can consume or produce.

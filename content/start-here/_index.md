This short path takes you from installation to a verified model. It uses the `intro-example.tapn` model supplied by TAPAAL, which demonstrates modeling, simulation, and verification in one file.

{{% notice note %}}
This draft was checked against the TAPAAL 4.0.4 download page and the `tapaal-gui` main branch on 2026-08-29. Installer details and menu labels may change in later releases.
{{% /notice %}}

2. [Open and understand the introductory model](first-model/).
3. [Simulate the model, create a query, verify it, and inspect the trace](first-model/#simulate-and-verify).

When you are ready to go further, continue to [Concepts](/concepts/) or the [Verification guide](/verification/).

The **Simulation History** widget records transition firings and time delays as you explore a net. It can also display traces produced by verification or imported from a trace file.

![Simulation history](/gui/simulation/simulation-history.png)

## Navigate a run

Select an entry in the history list to move to that marking. You can also choose **Simulator > Step backward** or **Simulator > Step forward**, use the controls in the **Simulation Control** widget, or press the left and right arrow keys.

If you move backward and then fire a new transition, TAPAAL discards the later part of the existing history and starts a new branch from that marking.

For a timed net, inspect the time delays and token ages at each step. A transition firing and a time delay are separate history entries, so use the sequence to understand both what changed and when it changed.

## Inspect a verification trace

When verification produces a witness or counterexample, TAPAAL can open the trace in a simulator tab. Step through the history and compare each marking with the query and the model's intervals, invariants, and urgent transitions.

If a result contains multiple traces, use the trace selector in the **Simulation Control** widget to switch between them. The available traces depend on the query, engine, and trace option selected for verification.

## Import and export

Use **Simulator > Export trace** to save the current trace and **Simulator > Import trace** to load a trace into the simulator. Keep the trace with the model, query, TAPAAL version, engine, and analysis settings when the result needs to be reproduced.

See [Results and traces](/verification/results/) for guidance on distinguishing witnesses, counterexamples, sampled traces, and incomplete runs.

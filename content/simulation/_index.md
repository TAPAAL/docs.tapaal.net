Simulation lets you explore a model one execution at a time. Use it to check the initial marking, follow enabled transitions, experiment with time delays, and inspect token ages before you formulate verification queries.

{{% notice note %}}
Simulation is an exploration and debugging aid. It does not establish that all executions satisfy a property; use [Verification](/verification/) for that.
{{% /notice %}}
